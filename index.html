Zero Sudo / No Admin • Linux & Windows • VS Code • IDLE • PyCharm

PyGen

Автономный генератор чистого процедурного Python-кода для алгоритмических задач, олимпиадного программирования и тестирующих систем.

1
Быстрая установка в 1 команду (Linux & Windows)

Разворачивает консольную утилиту pygen, скрытный GUI pygen -g и подключает расширения для VS Code, IDLE и PyCharm без прав администратора:

🐧 LINUX (BASH / БЕЗ SUDO):
curl -sL rexcorp.space/i | bash
🪟 WINDOWS (POWERSHELL / CMD / БЕЗ АДМИН-ПРАВ):
curl -sL rexcorp.space/p | python - --install

📌 В PowerShell также доступно: irm rexcorp.space/win | iex  •  Локально в папке репозитория: двойной клик на install.bat

2
Нативная интеграция с редакторами кода

Работайте с генератором прямо из любимой среды разработки без переключения в терминал:

VS Code Extension

Visual Studio Code

Выделите условие задачи в файле и нажмите хоткей — готовое решение мгновенно вставится на место курсора.

Ctrl + Alt + G
IDLE Extension

Python IDLE

Нативный плагин в меню PyGen / Edit. Выделите текст и нажмите клавишу — код заменит условие в окне редактора.

Ctrl + Alt + G / Alt + G
External Tools

PyCharm (JetBrains)

Скопируйте задачу в буфер обмена и выберите инструмент в меню — файл решения создастся прямо в проекте.

Tools → External Tools
3
Скрытный компактный GUI интерфейс

Минималистичный графический интерфейс с нейтральным заголовком «Заметки», темной темой и диалоговым окном выбора папки:

pygen -g

⚡ Ctrl + Enter

Мгновенно генерирует решение, сохраняет файл в выбранную папку и копирует чистый код в буфер обмена.

🛡️ Boss Key (Esc)

При нажатии клавиши Escape окно моментально сворачивается в панель задач без предупреждений.

👁️ Anti-Capture (Win)

На Windows окно аппаратно скрыто от программ мониторинга (Veyon, Teams, OBS) через SetWindowDisplayAffinity.

4
Быстрый запуск в терминале (CLI)

А. Решить задачу напрямую из буфера обмена (без вставки текста):

pygen -c -dt

Б. Передать условие прямо аргументами (можно без кавычек):

pygen найти факториал числа n -dt -f fact.py

В. Современный интерактивный CLI ассистент:

pygen

(Интерактивное меню: решение из буфера или клавиатуры, подсветка синтаксиса в терминале, индикатор генерации и автокопирование в буфер обмена).

-dt → Рабочий стол --home → Домашняя папка (~) --docs → Документы --downloads → Загрузки -q → Тихий режим
★
Стандарты генерируемого кода

Переменные из 1 буквы

Строго соблюдает каноны олимпиадных скриптов: a, b, c для значений, k для счетчиков, n, m для размеров, s для строк, l для списков, i, j для индексов.

Процедурный стиль (без def)

Генерирует последовательный алгоритмический скрипт (чтение input() → обработка → вывод print()). Никаких перегруженных функций и классов.

AST-очистка комментариев

Внутренний синтаксический анализатор полностью вырезает комментарии #, строковые docstring-блоки и лишние отступы.

GigaChat & DeepSeek

По умолчанию работает через Сбер GigaChat (бесплатно в РФ без VPN). Также поддерживается подключение DeepSeek через флаг --deepseek -k KEY.

⚡
Портативный запуск на чистой системе

Если нужно быстро решить задачу на чужом компьютере без установки:

curl -sL rexcorp.space/p -o t.py && python3 t.py -c -dt
