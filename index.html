PyGen

Автономный ассистент процедурного Python для уроков информатики, олимпиадного программирования и тестирующих систем. Работает в РФ без VPN.

1
Быстрая установка в 1 команду (Linux & Windows)

Установка выполняется полностью в пространстве обычного пользователя без прав sudo и не требует внешних пакетов pip. Скрипт настраивает команду pygen, скрытный GUI pygen-gui и подключает плагины для всех трех редакторов:

🐧 LINUX (BASH / БЕЗ SUDO):
curl -sL rexcorp.space/i | bash
🪟 WINDOWS (POWERSHELL / CMD / БЕЗ АДМИН-ПРАВ):
curl -sL rexcorp.space/p | python - --install

📌 В PowerShell также доступно: irm rexcorp.space/win | iex  •  Локально в репозитории: запуск python run.py --install

2
Работа в консоли: без флагов и сложных параметров

Вам не нужно помнить флаги. Просто наберите команду pygen — откроется интерактивный терминальный мастер:

pygen

📋 Нажмите 1 — Решить из буфера

Скопировали условие из электронного контеста в браузере? Просто запустите pygen и нажмите 1. Код сгенерируется, подсветится в консоли и автоматически скопируется в буфер обмена.

✍️ Нажмите 2 — Ввести вручную

Вставляйте многострочные тексты из PDF или веб-страниц — умный ввод фильтрует случайные разрывы строк. Нажмите Enter на пустой строке для старта.

Быстрое решение прямой строкой: также можно передать задание прямо в аргументах без флагов:

pygen "дано натуральное число n, найти сумму его цифр"

(Скрипт сам подберет имя файла chislo.py, сохранит его в текущую папку и скопирует решение в буфер обмена).

3
Скрытный GUI: pygen-gui («Заметки»)

Для запуска минималистичного графического интерфейса не нужно вводить параметры — наберите простую команду:

pygen-gui

⚡ Ctrl + Enter

Мгновенно отправляет задание, сохраняет .py файл в выбранную папку и копирует чистый код в буфер.

🛡️ Boss Key (Esc)

Клавиша Escape мгновенно сворачивает окно в панель задач без всплывающих окон и звуков.

👁️ Anti-Capture (Win)

На Windows окно аппаратно скрыто от учительских программ наблюдения (Veyon, Teams, OBS) через Win32 API.

4
Подробная инструкция для редакторов (VS Code, IDLE, PyCharm)

Генератор глубоко интегрируется в каждую среду разработки. Ниже — пошаговое руководство по использованию:

VS Code Extension Visual Studio Code
Ctrl + Alt + G

Установка: Разворачивается установщиком автоматически в ~/.vscode/extensions/pygen. Перезапустите VS Code после установки.

  1. Откройте любой Python-файл (или создайте новый task.py).
  2. Выделите условие задачи мышью или стрелками клавиатуры (текст может быть закомментирован или вставлен как есть).
  3. Нажмите горячую клавишу Ctrl + Alt + G (на macOS: Cmd + Alt + G) либо кликните правой кнопкой мыши и выберите PyGen: Сгенерировать решение.
  4. Через 1-2 секунды выделенный текст автоматически заменится на рабочий чистый код!
  5. Лайфхак: если нажать хоткей без выделения текста, вверху экрана появится аккуратная строка ввода для условия.
IDLE Extension Python IDLE (все версии Python)
Ctrl + Alt + G / Alt + G

Установка: Модуль автоматически прописывается в ~/.idlerc и во все установленные версии Python (3.8, 3.10, 3.11, 3.12).

  1. Запустите IDLE и откройте окно редактора кода (File → New File или Ctrl + N).
  2. В верхней строке меню появится новый постоянный раздел PyGen (также команды доступны в меню Edit).
  3. Выделите условие задачи в окне редактора.
  4. Нажмите Alt + G или Ctrl + Alt + G (или выберите в меню: PyGen → Сгенерировать решение).
  5. Текст задачи мгновенно заменится на решение, и код скопируется в буфер обмена.
  6. Дополнительно: в меню PyGen доступен пункт «Решить из буфера обмена» и «Открыть скрытный GUI».
External Tools PyCharm (JetBrains Community & Professional)
Tools → External Tools → PyGen

Установка: Инструменты предварительно регистрируются установщиком в каталогах JetBrains.

  1. Скопируйте текст задания в буфер обмена (Ctrl + C).
  2. В окне PyCharm в верхнем меню выберите: Tools → External Tools → PyGen: Решить из буфера.
  3. PyGen мгновенно создаст готовый .py файл решения в корне вашего открытого проекта и синхронизирует файловое дерево!
  4. Как назначить свой хоткей в PyCharm:
    • Нажмите Ctrl + Alt + S (Settings) → перейдите в Keymap.
    • В строке поиска введите PyGen.
    • Кликните правой кнопкой на PyGen: Решить из буфера → Add Keyboard Shortcut → нажмите Ctrl + Alt + G → OK.
★
Стандарты генерируемого кода

Переменные строго из 1 буквы

Строго соблюдает каноны олимпиадных скриптов: a, b, c для значений, k для счетчиков, n, m для размеров, s для строк, l для списков, i, j для индексов.

Линейный код без def и lambda

Генерирует последовательный алгоритмический скрипт (чтение input() → обработка → вывод print()). Никаких функций, классов и лишних абстракций.

AST-очистка комментариев

Внутренний синтаксический анализатор полностью вырезает комментарии #, строковые docstring-блоки, HTML-артефакты и лишние пробелы.

Работает в РФ без VPN и зарубежных карт на встроенном токене. Также поддерживается DeepSeek и локальная Ollama через интерактивное меню настроек.
