# PyGen

Быстрый и незаметный генератор чистого Python-кода без комментариев.
Не требует прав администратора (`sudo`), работает без `pip` (только стандартная библиотека Python) и работает без VPN.

## 🚀 Использование на Linux в 2 команды

### 1. Скачать (в одну команду):
```bash
curl -sO https://raw.githubusercontent.com/IliaBebebe/pygen/main/run.py
```
*(Или можно сохранить под неприметным именем: `curl -s https://raw.githubusercontent.com/IliaBebebe/pygen/main/run.py -o task.py`)*

---

### 2. Запустить (в одну команду):

#### Вариант А: Быстро с текстом задания (и пресетом папки)
```bash
# Сохранить прямо на Рабочий стол (Linux Desktop):
python3 run.py "проверка палиндрома" --desktop -f task1.py
# или коротко:
python3 run.py "проверка палиндрома" -dt -f task1.py

# Сохранить в домашнюю папку (~):
python3 run.py "таблица умножения" --home -f table.py

# Сохранить в Документы:
python3 run.py "сортировка списка" --docs -f sort.py
```

#### Вариант Б: Интерактивный режим (выбор папки по цифре)
```bash
python3 run.py
# Спросит задание, а затем покажет удобное меню:
#  1. Текущая папка (.)
#  2. Рабочий стол (Desktop)
#  3. Домашняя папка (~)
#  4. Документы (Documents)
#  5. Загрузки (Downloads)
#  6. Ввести свой путь вручную
```

#### Вариант В: Полностью скрытный режим (`-q`)
```bash
python3 run.py "программа подсчета гласных" -dt -f counter.py -q
```
*(В тихом режиме не выводит лишнего текста в терминал, просто сразу кладёт готовый файл на Рабочий стол).*

---

## ⚙️ Особенности
- **Готовые пресеты Linux:** Флаги `--desktop` (`-dt`), `--home`, `--docs`, `--downloads` автоматически находят правильные системные папки пользователя Linux (поддерживаются как русские `~/Рабочий стол`, так и английские `~/Desktop`).
- **Без функций (`def`):** Генерирует простой линейный код школьного уровня (чтение через `input()`, условия/циклы, вывод через `print()`), который выглядит максимально естественно для самостоятельной.
- **Без комментариев:** Полностью вырезает комментарии (`#`), inline-пояснения и docstring-блоки.
- **Без VPN:** Работает напрямую в РФ через Сбер GigaChat (ключ уже встроен, вводить ничего не нужно).
- **Без прав root:** Скрипт выполняется в обычном пространстве пользователя Linux.
