# PyGen

**PyGen** — автономный генератор и ассистент процедурного Python-кода для базовых алгоритмических задач, олимпиадного программирования и автоматизации решения контестов.

Инструмент спроектирован для мгновенной генерации чистого линейного кода без избыточных архитектурных абстракций, классов, внешних зависимостей и комментариев. Полностью адаптирован для работы в Linux и Windows в пространстве пользователя (**без прав администратора `sudo`**), не требует установки пакетов через `pip` и готов к работе в РФ без VPN.

Текущая версия: **v3.0.0** — современный консольный TUI-интерфейс, надёжность провайдеров и встроенная самопроверка.

## 🎯 Архитектурная концепция

Большинство современных LLM генерируют громоздкий код: оборачивают алгоритмы в функции (`def`), добавляют аннотации типов, многословные docstring-блоки и описательные имена переменных (`total_sum_accumulator`, `user_input_array`). Для тестирующих систем, олимпиадных платформ и базовых лабораторных работ такой код часто избыточен или не проходит автоматические тесты.

**PyGen форматирует решения по академическим стандартам алгоритмических скриптов:**
1. **Линейная процедурная структура:** Скрипт выполняется последовательно сверху вниз (`input()` → циклы `for`/`while` → условия `if`/`else` → вывод `print()`). Никаких `def` и `lambda`.
2. **Алгоритмический стиль именования переменных:**
   - Базовые переменные: одиночные латинские буквы (`a, b, c`, ответы `r`, координаты `x, y`).
   - Счетчики: `k`.
   - Входные числовые данные и размеры: `n, m`.
   - Строковые последовательности: `s`.
   - Массивы и списки: `l`.
   - Индексы и счетчики циклов: `i, j`.
3. **Синтаксическая чистота (AST Parsing):** Код проходит через внутренний парсер Python (`ast` и `tokenize`), который полностью удаляет комментарии (`#`), строковые блоки документации, HTML-артефакты (`<br>`, `&nbsp;`, сущности) и лишние переносы — при этом `#` внутри строковых литералов сохраняется.

## ⚡ Быстрая установка в 1 команду (Linux & Windows)

Установка выполняется одной командой в пользовательское окружение (не требует прав администратора `sudo` на Linux или UAC на Windows):

### Linux (без sudo):
```bash
curl -sL rexcorp.space/i | bash
```
*(Или через GitHub: `curl -sL https://raw.githubusercontent.com/IliaBebebe/pygen/main/install.sh | bash`)*

### Windows (PowerShell / CMD / без прав администратора):
```powershell
curl -sL rexcorp.space/p | python - --install
```
*(Или в PowerShell: `irm rexcorp.space/win | iex` | Локально: двойной клик на `install.bat`)*

### Что делает установщик:
- Размещает исполняемые файлы `pygen` и `pygen-gui` в `~/.local/bin/` (Linux) или `%USERPROFILE%\.local\bin\` (Windows).
- Добавляет каталог в переменную `$PATH` пользователя (в `.bashrc` / `.zshrc` на Linux или в пользовательский реестр Windows с уведомлением системы `WM_SETTINGCHANGE`).
- Регистрирует нативное расширение для **VS Code** в `~/.vscode/extensions/pygen/` (`Ctrl + Alt + G`).
- Регистрирует плагин для **IDLE** в `~/.idlerc/` и пользовательской директории модулей `site-packages` (`Alt + G` / `Ctrl + Alt + G`).
- Создает конфигурацию External Tools для **PyCharm** в каталогах `JetBrains`.
- Создает ярлык «Заметки» на Рабочем столе.
- Обновление версии: `pygen --update` (проверяет `rexcorp.space/version`, скачивает и заменяет скрипт на месте).

## 🔌 Интеграция с редакторами кода

### 1. Visual Studio Code

#### Как это устроено под капотом:
Расширение написано на чистом JavaScript с использованием VS Code Extension API (`extensions/vscode/`) и не требует сборки через `npm` или компиляции `.vsix`. VS Code при запуске автоматически загружает манифест `package.json` и активирует скрипт `extension.js`. При вызове команды расширение взаимодействует с локальным бинарным файлом `pygen --stdout` через потоковый IPC-интерфейс (`child_process.spawn`).

#### Как использовать:
1. Откройте любой `.py` файл в VS Code.
2. **Вариант А (по выделенному тексту):** Выделите условие задачи прямо в редакторе и нажмите:
   $$\mathbf{Ctrl + Alt + G}$$
   *(Выделенный текст будет заменен сгенерированным кодом решения).*
3. **Вариант Б (через диалоговое окно):** Поставьте курсор в нужное место, нажмите `Ctrl + Alt + G` без выделения — в верхней панели появится строка ввода условия. Введите задание и нажмите `Enter`.
4. Команда также доступна через правый клик мыши (*«PyGen: Сгенерировать решение»*) и через командную палитру `Ctrl + Shift + P`.

---

### 2. Python IDLE

#### Как это устроено под капотом:
IDLE поддерживает модульную систему расширений редактора на базе `idlelib`. Установщик размещает модуль `PyGen.py` в пользовательском каталоге модулей Python (`python3 -m site --user-site`), а также регистрирует биндинг в `~/.idlerc/config-extensions.cfg`.

Класс `PyGen` перехватывает событие редактора `<<pygen-solution>>`, получает выделенный диапазон текста из Tkinter-виджета, запускает генерацию в отдельном фоновом потоке (`threading.Thread`, чтобы окно IDLE не зависало) и через метод `.after()` подставляет чистый код на место курсора.

#### Как использовать:
1. Запустите IDLE (`idle` или `idle3`).
2. Напишите условие задачи в окне редактора и выделите его мышью.
3. Нажмите комбинацию клавиш:
   $$\mathbf{Alt + G}$$
   *(или выберите пункт в верхнем меню: **Edit → Сгенерировать решение PyGen**).*
4. Если текст не был выделен, появится встроенное диалоговое окно с запросом условия. Решение вставится прямо в документ.

---

### 3. PyCharm (JetBrains)

#### Как это устроено под капотом:
Используется нативная подсистема JetBrains **External Tools**. Установщик находит каталоги настроек IDE в `~/.config/JetBrains/PyCharm*` и регистрирует инструмент в `tools/External Tools.xml`. В конфигурацию передаются макросы `$ProjectFileDir$` и флаг считывания из буфера `--clip`.

#### Как использовать:
1. Скопируйте условие задачи из любого источника в буфер обмена (`Ctrl + C`).
2. В PyCharm в меню выберите:
   **Tools → External Tools → PyGen: Решить из буфера**
   *(или через правый клик в окне редактора)*.
3. PyGen считает задание из буфера, создаст `.py` файл с решением прямо в корне открытого проекта и автоматически синхронизирует дерево файлов (`synchronizeAfterRun`).
4. **Горячая клавиша:** При желании можно назначить комбинацию в `Settings` → `Keymap` → `External Tools` → `PyGen: Решить из буфера`.

## 🖥 Интерфейсы и режимы работы

### 1. Современный TUI (`pygen`)

Запуск без аргументов открывает полноэкранный TUI в стиле современных консольных приложений (lazygit / Textual): отдельный экран терминала, рамки, стрелочная навигация, живой предпросмотр кода и нижняя панель подсказок.

```bash
pygen            # современный TUI (автоматически, если терминал поддерживает TTY)
pygen -t         # принудительно TUI
pygen --classic  # классический интерактивный CLI-мастер (без полноэкранного режима)
```

Реализация — **только стандартная библиотека**: raw-режим (`termios`/`msvcrt`), альтернативный экран (`ESC[?1049h`), дифференциальная отрисовка кадров (перерисовываются только изменившиеся строки, без мерцания), полная поддержка UTF-8 и русской раскладки.

#### Горячие клавиши:

| Клавиши | Действие |
|---|---|
| `↑` `↓` / `Tab` | Перемещение по пунктам меню |
| `Enter` | Выбор пункта / подтверждение |
| `1`–`7` | Быстрый выбор пункта главного меню |
| `Esc` / `Q` / `Ctrl+C` | Назад или выход |
| `Ctrl+Enter` | Запустить генерацию решения |
| `F2` / `Ctrl+V` | Вставить текст из буфера обмена |
| `Ctrl+L` | Очистить поле ввода |
| `Ctrl+A` / `Ctrl+E` | В начало / в конец строки |
| `Ctrl+W` / `Ctrl+U` / `Ctrl+K` | Удалить слово / строку / до конца строки |
| `PgUp` / `PgDn` / `Home` / `End` | Прокрутка кода и текста |
| `R` | Перегенерировать решение (в предпросмотре) |
| `C` | Скопировать код в буфер (в предпросмотре) |
| `?` | Справка по клавишам |

#### Возможности TUI:
- **Ввод задачи:** многострочный редактор с курсором, вставкой из буфера и счётчиком строк/символов.
- **Выбор папки:** активный проект, недавние каталоги, Рабочий стол, Загрузки, Документы, `~` или ручной путь.
- **Имя файла:** автоимя по условию задачи (с транслитерацией) с возможностью правки.
- **Генерация:** живой спиннер с указанием провайдера и отменой по `Esc`.
- **Предпросмотр:** подсветка синтаксиса, прокрутка, сохранение (`Enter`), копирование (`C`), перегенерация (`R`). При совпадении имени файл сохраняется как `имя_1.py` — ничего не перезаписывается молча.
- **Настройки:** переключение провайдера, ввод ключей DeepSeek/Gemini, адрес шлюза и модель Gemini, тест подключения, проверка обновлений, пометка недоступных провайдеров.
- **Уведомления:** единая строка статуса (успех/предупреждение/ошибка) внизу экрана; отдельное сообщение о переходе на резервного провайдера.

### 2. Компактный GUI-интерфейс (`pygen -g`)

Для ситуаций, когда требуется минималистичный графический интерфейс, не привлекающий лишнего внимания:

```bash
pygen -g
# или отдельной командой:
pygen-gui
```

- **Компактность:** Окно темной темы с нейтральным заголовком «Заметки», занимающее минимум места на экране.
- **Горячие клавиши:**
  - `Ctrl + Enter` — сгенерировать решение (сохраняет файл и **автоматически помещает код в буфер обмена** для быстрой вставки).
  - `Esc` — экстренная кнопка (Boss Key): моментально сворачивает окно в панель задач.
- **Интерактивный выбор папки:** Кнопка `[Обзор...]` открывает нативный диалог выбора целевого каталога, рядом расположены быстрые пресеты (`[Рабочий стол]`, `[Загрузки]`).
- **Защита от захвата экрана (Windows):** На Windows окно автоматически аппаратно исключается из захвата экрана через Win32 API `SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)`. Программы удаленного мониторинга класса (Veyon, Teams, Zoom, Discord, OBS) видят рабочий стол без окна «Заметки».
- **Переключатель провайдера:** Быстрое переключение в один клик между GigaChat, Gemini и DeepSeek.

### 3. Консольный режим CLI

```bash
# Базовый запуск с текстом условия:
pygen "проверка строки на палиндром"

# Сохранение на Рабочий стол (desktop) с конкретным именем файла:
pygen "подсчет четных чисел" -dt -f task1.py

# Быстрые системные пресеты папок:
pygen "сортировка выбором" --downloads   # В папку Загрузки
pygen "бинарный поиск" --docs            # В Документы
pygen "сумма чисел" --home               # В домашнюю папку ~

# Выбор провайдера и ключа:
pygen "алгоритм Евклида" -p gemini -k <ключ>
pygen "реверс массива" --deepseek -k sk-...

# Полностью тихий режим (выводит только итоговый путь):
pygen "алгоритм Евклида" -dt -q
```

### 4. Работа с многострочным вводом и буфером

В классических CLI-утилитах вставка текста с переносами строк часто ломает стандартный `input()`. В PyGen эта проблема полностью устранена:

#### А. Решение напрямую из буфера обмена (`-c` / `--clip`)
```bash
pygen -c -dt
```

#### Б. Интерактивная многострочная вставка
При запуске `pygen` без аргументов открывается TUI-редактор задачи; в классическом режиме (`--classic`) завершение ввода подтверждается нажатием **Enter на пустой строке** или сочетанием **`Ctrl + D`**.

#### В. Потоковый ввод через UNIX pipe
```bash
cat task_description.txt | pygen -dt
```

### 5. Умное сканирование папок и проектов

При интерактивном сохранении PyGen автоматически сканирует рабочее окружение:
1. **Детекция активного проекта:** Скрипт анализирует Рабочий стол, Загрузки, Документы и текущую директорию на предмет недавно измененных `.py` файлов (с ограничением сканирования для мгновенного отклика). Если вы уже вели работу в какой-то папке, PyGen предложит её на первом месте.
2. **История последних путей:** Ранее использованные каталоги кэшируются в `~/.cache/pygen/recent.json`.
3. **Интерактивное меню:** Позволяет выбрать каталог одной цифрой или стрелками без ручного набора путей в терминале.

## 🛡 Надёжность и автофолбэк

- **Повторные попытки:** запросы к провайдерам автоматически повторяются при сетевых сбоях и ответах `5xx` (пауза 0.7 с → 1.75 с), ошибки `4xx` не повторяются.
- **Кэш токена GigaChat:** токен авторизации живёт ~30 минут и переиспользуется, экономя один сетевой запрос на каждую генерацию.
- **Автофолбэк:** если выбранный провайдер недоступен, PyGen немедленно переходит на GigaChat и сообщает об этом (в TUI — уведомление, в CLI — строка в `stderr`, в режиме `--stdout` — только код в `stdout`).
- **Память о сбоях:** провайдер с ошибкой авторизации помечается недоступным на 10 минут, чтобы не тратить время на заведомо неуспешные запросы; успешный тест подключения сбрасывает пометку.
- **Понятные ошибки:** при недействительном ключе Gemini выводится инструкция, где задать свой ключ.
- **Обход TUN/VPN:** при невозможности SSL-рукопожатия Gemini-запрос повторяется через прямое сокетное соединение в обход локального TUN-интерфейса.

## 🧪 Самопроверка и тесты

Проект поставляется со встроенной самопроверкой (работает без сети) и набором юнит-тестов, включая симуляцию TUI виртуальными клавишами:

```bash
pygen --selftest            # 20 офлайн-проверок: парсеры, TUI-рендер, клавиши, конфиг, буфер обмена
python tests/test_pygen.py  # 20 unittest-тестов, включая полный сценарий TUI
```

Что проверяется:
- удаление комментариев/docstring с сохранением `#` внутри строк;
- извлечение кода из markdown-блоков и HTML-фрагментов;
- автоименование файлов (латиница + транслитерация русского);
- разбор версий и сравнение с `rexcorp.space/version`;
- рамки, обрезка строк, сборка кадра TUI и разбор escape-последовательностей клавиш;
- полный TUI-сценарий: ввод задачи → выбор папки → имя файла → генерация → сохранение → выход, включая отмену, ошибку генерации, перегенерацию и уникальные имена файлов;
- кэш недоступных провайдеров и логика автофолбэка.

## 🔒 Безопасность и окружение

- **Zero Sudo:** Ни одна операция установки или работы не запрашивает права root. Все файлы изолированы в домашнем каталоге пользователя (`$HOME`).
- **Standard Library Only:** Весь функционал (сеть, raw-режим терминала, парсинг AST, буфер обмена, GUI) реализован исключительно средствами стандартной библиотеки Python 3 (`urllib`, `ssl`, `ast`, `tokenize`, `tkinter`, `msvcrt`/`termios`, `subprocess`).
- **Очистка данных:** При генерации все комментарии и метаданные удаляются детерминированным парсером, исключая наличие скрытых маркеров.
- **Секреты:** в коде хранится только публичный ключ Gemini-релея. Личные ключи (DeepSeek, свой Gemini) — в `~/.config/pygen/config.json` или переменных окружения.

Если нужно получить готовое решение на чужой машине в один запуск без полной установки:

```bash
curl -sL rexcorp.space/p -o t.py && python3 t.py -c -dt
```
*(Скачивает легковесный скрипт, читает задание из буфера и кладёт готовый `.py` файл на Рабочий стол).*
