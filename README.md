# PyGen

Быстрый и незаметный генератор чистого Python-кода без комментариев.
Не требует прав администратора (`sudo`), работает без `pip` (только стандартная библиотека Python) и работает без VPN.

## 🚀 Использование на Linux в 2 команды

### 1. Скачать (в одну команду):
```bash
curl -sO https://raw.githubusercontent.com/IliaBebebe/pygen/main/run.py
```
*(Или можно сохранить под неприметным именем: `curl -s https://raw.githubusercontent.com/IliaBebebe/pygen/main/run.py -o task.py`)*

---

### 2. Запустить (в одну команду):

#### Вариант А: Быстро с текстом задания
```bash
python3 run.py "напиши функцию проверки палиндрома" -f task1.py
```

#### Вариант Б: Интерактивный режим (спросит задание и путь)
```bash
python3 run.py
```

#### Вариант В: Полностью скрытный режим (`-q`)
```bash
python3 run.py "программа подсчета гласных" -d ./project -f counter.py -q
```
*(В тихом режиме не выводит лишнего текста в терминал, просто сразу кладёт готовый файл).*

---

## ⚙️ Особенности
- **Без функций (`def`):** Генерирует простой линейный код школьного уровня (чтение через `input()`, условия/циклы, вывод через `print()`), который выглядит максимально естественно для самостоятельной.
- **Без комментариев:** Полностью вырезает комментарии (`#`), inline-пояснения и docstring-блоки.
- **Без VPN:** Работает напрямую в РФ через Сбер GigaChat (ключ уже встроен, вводить ничего не нужно).
- **Без прав root:** Скрипт выполняется в обычном пространстве пользователя Linux.
